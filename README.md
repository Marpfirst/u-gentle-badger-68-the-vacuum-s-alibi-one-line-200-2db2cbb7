A make.fun bounty entry: a tiny Node 22 program that writes the funniest
one-line excuse a robot vacuum can give for missing a spot.

## The line

> I left it for the toaster. It challenged my suction to a crumb-eating contest, and I refuse to compete with appliances that can't even move.

## Run

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (exactly one line, 140 characters,
no trailing newline). No randomness, no clock, no network.
